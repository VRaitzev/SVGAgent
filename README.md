# ✨ Antigravity — AI-студия изометрических векторных композиций

Интерактивная веб-студия и мультимодальный AI-агент (VLM ReAct) для автоматической генерации, валидации и редактирования изометрических SVG-иллюстраций по правилам дизайн-системы.

![Antigravity Studio UI](docs/studio_ui.jpg)

---

## 🎯 Ключевые возможности и выполнение требований ТЗ

* **Смысловые слои и роли объектов (`Main` ↔ `Background`):**
  * Главные объекты (`main`) сохраняют конструктивные чёрные контуры, глубокие падающие тени и белые страницы, окрашиваясь в акцентные цвета выбранной палитры.
  * Фоновые объекты (`background`) автоматически переводятся в **объёмный 4-ступенчатый монохром** (тёмный контур, мягкая тонированная тень, полутон и светлая грань) строго в пределах фоновых цветов схемы (`bg_colors`), сохраняя 3D-читаемость граней в точном соответствии с референсами Figma.
  * Любой объект на холсте переключается между состояниями **Главный ↔ Фоновый** в один клик (`toggle_item_role`).
* **Единый изометрический масштаб (`uniform_scale`) и уровни детализации (`L` / `S`):**
  * Соблюдается правило истинной изометрии: пропорции объектов не искажаются относительно друг друга, масштабирование выполняется синхронно.
  * Мгновенное переключение сцены между детализированными (`L`) и компактными (`S`) версиями ассетов по единому `concept_key` с сохранением центров координат и цветовой схемы.
* **Умная геометрическая и цветовая валидация:**
  * Поддержка плотной журнальной вёрстки: разрешено осознанное наслоение мелких аксессуаров (ручка, смартфон, монета) поверх крупных плоских баз (книга, папка) и композиционная обрезка краями холста (`Deliberate Crop`, $\ge 30\%$ площади внутри кадра).
  * Автоматическая блокировка цветовых нарушений (акцентные цвета главных объектов запрещены в фоновом слое).
* **Мультимодальный AI-агент с циклом визуальной самопроверки (VLM Self-Critique Loop):**
  * Агент работает в двух режимах доступа к библиотеке: **Весь каталог** (`full_catalog`) или **Гибридный RAG-поиск** (`LanceDB` + метафорический стемминг `Top-K`).
  * В режиме **VLM** агент рендерит текущую сцену через `resvg_py` с координатной разметкой (`200, 400, 600 px`), сжимает кадр в компактный JPEG и визуально проверяет композицию на отсутствие физических коллизий и слипания теней (*Tangent Trap*).
  * **Оптимизация контекста и бюджета шагов:** изображения передаются только на текущем шаге проверки и не накапливаются в истории сообщений графа, а правки объединяются в пакетные транзакции (`apply_scene_diff`) с жёстким лимитом шагов.

## 🏗 Архитектура проекта

```text
├── src/
│   ├── backend/
│   │   ├── server.py          # FastAPI сервер (REST API, раздача статики, экспорт SVG/PNG)
│   │   ├── AgentCore.py       # Мультимодальный ReAct-агент (LangGraph, JPEG-сжатие, контроль бюджета)
│   │   ├── agent_tools.py     # Инструменты агента (поиск, сборка сцены, пакетный diff, VLM-инспекция)
│   │   ├── scene_session.py   # Транзакционная сессия (Undo/Redo/Revert, L↔S, Main↔Background)
│   │   ├── composition.py     # Ядро геометрии холста 800×800, слоёв и правил валидации ТЗ
│   │   ├── palette.py         # Цветовые схемы и алгоритм распределения цветов по яркости (luminance)
│   │   ├── svg_image.py       # Парсер SVG-метаданных, нормализация CSS/HEX-цветов и viewBox
│   │   ├── svg_store.py       # Хранилище компонентов на базе LanceDB (векторный + метафорический поиск)
│   │   └── renderer.py        # Сборка итогового SVG-дерева, изоляции ID и рендеринг в PNG (resvg_py)
│   └── frontend/
│       ├── App.jsx            # Интерактивный редактор (Moveable, слои, палитры, чат с VLM, история)
│       └── api.js             # Клиент взаимодействия с FastAPI
└── data/
    ├── lancedb/               # Предзаполненная база из 28 изометрических SVG-компонентов (L/S, Main/Bg)
    └── png/                   # Отрендеренные превью компонентов
